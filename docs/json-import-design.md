# تصميم رفع JSON والاستيراد الآمن

يتعامل النظام مع ملف JSON الذي ينزله من زر النسخة الاحتياطية بوصفه ملفًا كاملاً للقراءة والأرشفة. عند رفعه، تُجرى معاينة بلا أي كتابة إلى قاعدة البيانات، وتظهر أعداد السجلات وحقول غير مدعومة وتحذيرات السلامة.

> لا تُستورد كلمات المرور أو بصماتها أو جلسات الدخول أو معرفات المصادقة الخارجية تحت أي ظرف.

يدعم زر الاستيراد **دمج دليل البيانات الأساسية** فقط: الأقسام، الموظفون كملفات غير مرتبطة بحساب دخول، التصنيفات، أنواع المكونات، الشركات، الأصناف، وقوائم مكونات المنتجات. تتم المطابقة بالمفاتيح التشغيلية المستقرة، مثل رمز القسم وكود الموظف ورمز الشركة ورقم الصنف. يُسمح بالإضافة والتحديث الوصفي، لكن لا يسمح الاستيراد بتعديل الرصيد أو المحجوز أو المعاملات أو الطلبات أو الفواتير أو حالات الصيانة والشراء والتجميع؛ فهذه سجلات تدقيقية لا يجوز تغييرها عبر ملف.

| المرحلة | النتيجة | هل تكتب بيانات؟ |
| --- | --- | --- |
| رفع الملف والتحقق | التأكد من الصيغة والإصدار وغياب الحقول الحساسة | لا |
| المعاينة | إظهار أعداد الإضافة والتحديث والسجلات المحظورة | لا |
| تأكيد الإدخال | عبارة تأكيد صريحة من الأدمن | لا |
| الدمج | إضافة/تحديث البيانات الأساسية في معاملة واحدة | نعم |

لا يمثل هذا الزر بديلًا عن استعادة الكوارث الكاملة على قاعدة بيانات حية. الاستعادة الكاملة لسجلات العمليات والحسابات تتطلب بيئة نظيفة وخطوات إدارية مضبوطة حتى لا يُستبدل سجل تدقيقي قائم.
