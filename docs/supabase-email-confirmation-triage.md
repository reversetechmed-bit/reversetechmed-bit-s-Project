# معالجة حد رسائل تأكيد البريد

## الحالة المرصودة

أثناء تفعيل حساب موظف معتمد، أعاد Supabase الرسالة `email rate limit exceeded`. هذه الرسالة تخص حد إرسال رسائل تأكيد البريد في مزود المصادقة، ولا تعني أن البريد المعتمد أو كود الموظف غير صحيحين.

## إعداد المشروع وقت الفحص

كان مزود البريد مفعلاً، وخيار **Confirm email** مفعلاً أيضاً. لذلك تنفذ عملية التسجيل إنشاء الحساب ثم محاولة إرسال رسالة تأكيد إلى البريد. عند بلوغ الحد المؤقت، يفشل الإرسال ويجب عدم تكرار المحاولة فوراً.

## القرار التشغيلي

طُرح إيقاف خيار تأكيد البريد لأن دخول الموظفين مقيد مسبقاً بالبريد المعتمد وكود الدخول الذي يصدره الأدمن، لكن المسؤول اختار الإبقاء على تأكيد البريد مفعلاً. لذلك لا يغيّر النظام إعداد Supabase ولا يحاول تجاوز حد الإرسال.

## سلوك الواجهة

تعرض شاشة التفعيل الآن رسالة عربية صريحة عند هذا الخطأ، تفرق بين حد البريد المؤقت وبين فشل بيانات التفعيل. في هذه الحالة يوقف الموظف المحاولة ويعود للأدمن، ولا يعيد إدخال البريد أو الكود مراراً.
