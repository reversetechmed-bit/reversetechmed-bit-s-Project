# تصميم التتبع والتحكم التشغيلي

## مبادئ غير قابلة للتنازل

لا يُعدّل أي رصيد فعلي عند إنشاء باركود أو رقم تسلسلي أو جلسة جرد أو أمر عمل. يصبح تغيير الرصيد ممكنًا فقط داخل معاملة قاعدة بيانات مؤكدة ومقترنة بسجل حركة غير قابل للحذف. تبقى كمية القطعة الفعلية، والمحجوز، والعهدة حقولًا مستقلة؛ ويحسب المتاح داخل المخزن بالصيغة: **الفعلي − المحجوز − العُهدة**.

| المجال | القرار التشغيلي | الأثر على المخزون |
| --- | --- | --- |
| باركود وQR | رمز فريد للصنف ورمز اختياري لموقع التخزين، مع صفحة طباعة ملصق | لا أثر |
| تتبع تسلسلي | سجل وحدة مفردة للبوردة أو الجهاز، يرتبط بصنف واحد وحالة وموقع أو حائز | لا أثر عند التسجيل؛ يتحرك فقط عبر عمليات معتمدة |
| الجرد | جلسة مجمدة بتوقعات الرصيد، وأسطر عدّ، ومراجعة فرق قبل الاعتماد | فرق معتمد فقط يسجل حركة جرد |
| أمر العمل | إنتاج أو إصلاح، له مسؤول وأولوية ومرحلة وفحص جودة | لا أثر حتى إتمام عملية إنتاج/إصلاح صريحة |
| التشليح | مصدر واحد وقطع مخرجة مختارة بحالة قابلة لإعادة الاستخدام | يزيد رصيد القطع المعتمدة فقط، مع مصدر وحالة |
| التقرير الدوري | إعداد تقرير يديره الأدمن وتنفذه مهمة دورية موثوقة | لا أثر |

## الباركود والتتبع التسلسلي

يستعمل كل صنف **باركودًا داخليًا فريدًا** قابلًا للتوليد أو الإدخال اليدوي. ويُستخدم QR لتضمين رابط داخلي أو قيمة الباركود نفسها، وليس لإخفاء بيانات اعتماد. أما البوردة أو الجهاز الذي يحتاج تتبعًا فرديًا، فيحمل رقمًا تسلسليًا فريدًا في سجل مستقل حتى يمكن معرفة حالته ومكانه والحائز الحالي وتاريخ الصيانة أو أمر العمل.

## الجرد وفروقات الرصيد

يفتح الأدمن جلسة جرد باختيار النطاق، ثم تحفظ كل سطر قيمة الرصيد المتوقع لحظة فتح الجلسة مع الكمية المعدودة والملاحظة. لا يعدّل العدّ الرصيد. بعد المراجعة، يعتمد الأدمن الفروق المطلوبة فقط؛ ويُكتب لكل فرق معتمد سجل حركة مستقل قبل تحديث الرصيد. لا يجوز اعتماد جلسة ملغاة أو مكتملة، ولا اعتماد سطر بلا كمية معدودة.

## الإنتاج والإصلاح والتشليح

أمر العمل يختلف عن أمر التجميع الحالي: هو بطاقة تنفيذ تتابع الشخص المسؤول والأولوية والمرحلة والاختبار، ويمكن ربطه بمنتج أو وحدة تسلسلية. يظل التجميع الذري الحالي مسؤولًا عن استهلاك BOM وإنتاج الرصيد؛ ويستطيع أمر العمل استدعاءه عند الإكمال بدل تكرار منطق خصم المكونات.

التشليح يغلق وحدة أو منتجًا كمصدر، ثم يسمح بإعادة قطع محددة فقط بعد تسجيل الحالة. لا يعيد النظام تلقائيًا كل مكونات BOM، لأن الواقع قد يحتوي قطعًا غير صالحة أو مفقودة. لكل قطعة معادة يسجل المصدر وسبب إعادة الاستخدام وحالتها.

## الصلاحيات والتقارير

تستمر أدوار **admin / engineer / viewer** كما هي. تضاف أدوار تشغيلية أدق ضمن ملف الموظف: أمين مخزن، فني صيانة، ومشتريات. يطبق الخادم الصلاحيات وفق قدرات محددة، لا وفق إخفاء الأزرار فقط. يستطيع الأدمن دائمًا إدارة كل المسارات.

التقارير الدورية الأولى تكون داخل النظام كتنبيه تشغيلي قابل للمراجعة، لأن إرسال البريد الخارجي يحتاج إعدادًا منفصلًا. تدعم تقارير النواقص، العهد المتأخرة، الصيانة المفتوحة، وفروق الجرد. تنفذ المهمة الدورية عبر خدمة المنصة الموجودة بالفعل وبشكل متكرر آمن، لا عبر مؤقت داخل الخادم.
