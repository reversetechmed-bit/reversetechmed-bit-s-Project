# قائمة التحقق الحي المؤجل

تغطي الاختبارات الآلية تدفقات البيانات والصلاحيات والخدمات الخلفية، لكن التحقق التالي يتطلب جلسة حقيقية ولا يجب تنفيذه من دون موافقة صاحب الحساب.

| الجلسة | المسارات/الإجراءات المطلوب عرضها فقط | سبب الحاجة للجلسة |
| --- | --- | --- |
| أدمن | لوحة المتابعة، الموظفون، المستخدمون، الشركات، التصنيفات، الطلبات، الفواتير، الإشعارات | تأكيد إظهار الصلاحيات والإجراءات المقيدة وحالة ربط الموظف بالحساب |
| مستخدم/مهندس | المخزون، طلباتي، تأكيد الاستلام، الإشعارات | تأكيد نطاق البيانات الشخصية وتجربة المتابعة |
| أدمن ثم مستخدم | طلب → اعتماد → حجز → تسليم → تأكيد استلام | تحقق واجهة كامل دون تنفيذ أي كتابة على البيانات الحالية إلا بموافقة صريحة |

لا تُنفّذ أي عملية إنشاء أو اعتماد أو تسليم أو ربط حساب خلال التحقق المرئي دون تأكيد منفصل من المسؤول.
