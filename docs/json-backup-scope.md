# نطاق النسخة الاحتياطية JSON

ينشئ الأدمن ملف JSON واحدًا قابلًا للتنزيل يحتوي على وقت الإنشاء، إصدار الصيغة، وعدد السجلات لكل مجموعة. ويشمل دليل الشركة، المخزون، الطلبات والفواتير، الصيانة والشراء والتجميع، والتنبيهات وسجل التدقيق وإعدادات التشغيل. يُحافظ على المعرفات الداخلية والعلاقات كي يكون الملف مرجعًا دقيقًا عند الاستعادة المنضبطة.

لا يصدّر الملف كلمات المرور أو بصماتها أو رموز الدعوة، ولا جلسات المتصفح أو مفاتيح البيئة أو معرفات المصادقة الخارجية. تحتفظ ملفات الموظفين بالمعلومات التشغيلية، لكن لا يمكن أن تعيد إنشاء حسابات المصادقة تلقائيًا؛ تُعاد الحسابات أو تُربط يدويًا في بيئة الاستعادة ثم تُراجع العلاقات.

| مجموعة البيانات | ضمن النسخة | الاستبعاد المتعمد |
| --- | --- | --- |
| الأقسام والموظفون والحسابات الداخلية | نعم | بصمة كود الدخول، معرف المصادقة الخارجي، طريقة الدخول |
| المخزون والشركات وقوائم المكونات | نعم | لا يوجد |
| الطلبات والفواتير والمعاملات والأنشطة | نعم | لا يوجد |
| الصيانة والمرتجعات والشراء والتجميع | نعم | لا يوجد |
| التنبيهات وإعدادات مهمة المتابعة | نعم | لا توجد أسرار في الجداول |
| الجلسات وكلمات المرور ومفاتيح البيئة | لا | دائمًا |
