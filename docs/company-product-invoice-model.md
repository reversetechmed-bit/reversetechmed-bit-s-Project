# نموذج الشركات والمنتجات والفواتير

يُعرَّف **الشخص المستلم** بأنه الجهة الفعلية التي تُسلَّم لها القطعة، بينما يُعرَّف **مقدم الطلب** بالحساب الذي أرسل طلب الصرف. يحفظ الطلب اسم المستلم وقسمه ومرجع المشروع أو الجهاز وملاحظته، ثم تُلتقط هذه القيم في فاتورة التسليم حتى لا يتغير السجل التاريخي إذا عدّل المستخدم ملفه لاحقًا. يسجل أدمن المخزن ملاحظة التسليم الاختيارية، ويُولّد تاريخ ووقت التسليم تلقائيًا عند التأكيد.

تمثل **الشركة** جهة التعامل الخارجية. يرتبط كل سجل في قسم المنتجات اختياريًا بشركة واحدة وبحالة منتج: `finished` للمنتج التام، أو `work_in_progress` للمنتج تحت التشغيل. يمثل جدول **مكونات المنتج** قائمة المواد؛ فيربط المنتج بسجلات المكونات الموجودة فعليًا في المخزون مع كمية مطلوبة لكل مكون، ولا ينشئ نسخة أو رصيدًا مكررًا من المخزون.
